# Security Policy

Please report vulnerabilities privately via
**[GitHub security advisories](https://github.com/sinceaihq/doctosheet/security/advisories/new)**, or e-mail
**builders@sinceai.fi**. Do not open public issues for vulnerabilities, and never attach real invoices.

In scope: anything that lets a document or a web page execute code, read files, exhaust the machine, use the local
server from another site, or inject formulas into exported spreadsheets. See [docs/SECURITY.md](docs/SECURITY.md) for
the threat model.
